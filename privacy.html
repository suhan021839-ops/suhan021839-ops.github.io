Privacy Policy

Effective date: October 21, 2026 · Applies to the current personal Windows uploader and this information website.

1. Operator and purpose

Something’s Off Automation is operated by the GitHub account suhan021839-ops for the owner’s management of the 이상한 하루 | Something’s Off channel. It uses YouTube API Services to identify the authorized channel, upload reviewed videos, and check upload processing results.

2. Information accessed and stored

  • Google OAuth access and refresh tokens, plus the application’s OAuth client configuration, to maintain authorized API access.
  • The connected YouTube channel ID and title, returned after authorization.
  • Videos the owner places in the local upload queue, together with titles, descriptions, visibility, audience and synthetic-media settings, and optional publication times.
  • Local queue records, file checksums, upload session information, YouTube video IDs, processing results, timestamps, retry counts and error records.

The current program requests https://www.googleapis.com/auth/youtube.readonly and https://www.googleapis.com/auth/youtube.upload. Although those scopes permit broader access, the current implementation uses read access for channel identification and video processing/status checks. It does not read Gmail, contacts or Google Drive files and does not collect Google passwords.

3. Use and sharing

Data is used to connect the selected channel, validate and process the owner’s upload queue, avoid duplicate submissions, resume transfers and report failures. Video files, metadata and authorization data needed for requests are transmitted to Google/YouTube through their HTTPS services. Published video visibility follows the owner’s chosen YouTube settings.

The current uploader does not send Google API data or OAuth tokens to AI model providers, advertising services or data brokers. The operator does not sell Google user data or use it for advertising, profiling or training generalized AI models. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

4. Local storage and security

OAuth credentials and tokens are encrypted with Windows Data Protection API (DPAPI), tied to the local Windows user. Upload session information is also protected. Media files, configuration and queue/history records remain in the local application directory and are not all encrypted by this application. The owner is responsible for protecting the PC, its Windows account and any backups.

This public website and its repository do not contain the uploader’s credentials, private media or local queue database. The current uploader has no operator-run cloud database.

5. Retention, revocation and deletion

Local data remains on the owner’s PC until the owner removes it; the current version does not include an automatic retention or purge feature. Keep only records needed for current channel operations and remove data when no longer needed.

To stop access, remove this app’s permission in Google Account connections. This revokes authorization but does not automatically erase local files or videos already uploaded to YouTube.

To remove local application data: disable the SomethingsOff-UploadWorker scheduled task, close the application, then delete its local data, inbox and logs folders and any backups you created. Deleting data removes the stored authorization, channel configuration and queue/history database. This also removes local duplicate-detection history. Do not restart or reconnect the program if you intend it to remain inactive.

Delete previously uploaded videos separately in YouTube Studio. Google handles data on its services under the Google Privacy Policy.

6. Website hosting

This information website is hosted by GitHub Pages. It has no analytics scripts, advertising, contact forms or application-level cookies. GitHub may log visitor IP addresses and other information for hosting and security purposes; see the GitHub Privacy Statement. Information voluntarily submitted to GitHub Issues is public and is processed by GitHub.

7. Changes and contact

This policy will be updated before integrations materially change how Google user data is handled. For questions or help deleting data, contact the operator through the support email shown on the application’s Google consent screen. For non-sensitive questions, use the project support page. Never post tokens or private account information there.
